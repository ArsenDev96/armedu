# Project audit history

`PROJECT_STATE.md` retains dated audit narrative because later decisions refer to specific
findings. Sections explicitly headed or marked **Historical** are snapshots, not the current
source of truth. The opening current-state sections supersede their old counts, route examples,
coverage statements and test totals.

Future large audit snapshots should move into this directory, with a short pointer left in
`PROJECT_STATE.md`, so current facts and historical evidence remain distinguishable.
